# Virtual Antenna Array Direction of Arrival Estimation Based on FMCW Radar Simulation Data [with MATLAB Code]

Introduction: Millimeter Wave Technology has great applicability in automotive radar. Typical frequency bands for millimeter wave automotive radar are 76-81 GHz. High frequencies allow for the use of small antennas that can be installed behind the bumper of a vehicle. Additionally, the wide available bandwidth enables high target distance resolution [1]. Advanced automotive radar uses FMCW (Frequency Modulated Continuous Wave) to transmit at millimeter wave frequencies, which allows for high-resolution target distance and velocity estimation at a cost much lower than LiDAR (Light Detection and Ranging) technology. Automotive radar for autonomous driving requires high angle discrimination capability. Using a large antenna array will improve angle resolution, however, the resulting large package size will make integration on vehicles difficult. Although for traditional phased array radar, small package size means low angle resolution, for MIMO (Multiple Input Multiple Output) radar [2], packaging size is not a limiting factor. This is because MIMO radar can synthesize a virtual array with a large aperture using only a few transmit and receive antennas [3]. Automotive MIMO radar uses FMCW waveforms, along with some mechanism ensuring waveform orthogonality.
Through this semester's project, we designed an FMCW radar emulator working at 77 GHz with a bandwidth of 150 MHz. We used unit average constant false alarm rate on the distance-Doppler shift plot to identify two different stationary moving targets. Then, we employed three methods for DOA estimation based on FFT, MUSIC, and compression-sensing.
Section Two details the FMCW radar emulation. Section Three introduces CA-CFAR detection, and Section Four discusses the DOA estimation methods based on FFT, MUSIC, and compression-sensing. Finally, Section Five concludes the paper.
